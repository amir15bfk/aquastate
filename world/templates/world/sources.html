Refresh

The world layer is designed to be refreshed without a page being open. The UI also has a Refresh live data button that starts a single-flight background refresh.

python manage.py bootstrap_world              # fetch + recompute + snapshot
python manage.py bootstrap_world --offline    # use cached/source files only
python manage.py bootstrap_world --limit 10   # smoke run
python manage.py load_dam_atlas --reset       # rebuild the dam catalogue
python manage.py dedupe_dams                  # merge duplicate monitored rows

For unattended operation, run python manage.py refresh_world --loop --interval 900 in a second terminal. The page polls /api/world/meta/ every 60 seconds and updates the map when the snapshot version changes.

Honesty rules

  • Live is a successful fetch with a stored timestamp, not a label of intent.
  • Cached is the last successful copy; the UI never calls it live.
  • Modeled storage is a mass-balance/reference estimate, not SCADA telemetry.
  • Proxy groundwater uses root-zone wetness when no aquifer inventory exists.
  • Missing data is neutral with low confidence; it is never a hidden zero or a fake 50 in the score.
  • Scenario values are simulated, tagged, and never overwrite an observed snapshot.
  • “Not for operational decisions” appears in the footer and in the API language.
