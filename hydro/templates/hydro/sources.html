Sources and lineage

The dashboard separates live measurements, operational forecasts, reference inventories, modeled reconstruction and synthetic fallback. The source ledger is shown with every snapshot so a reader can see what is carrying the number.

No source is dressed up as another. NASA POWER and Open-Meteo are live/keyless public services. Public dam tables supply names, locations and screening capacities. Current storage and the ten-year history are modeled from rainfall, allocated demand and evaporation. A fallback is labeled as fallback.

What each kind means

KindMeaningEffect on confidence
LiveFetched from a public API and stored with a timestamp.High (0.90–0.95)
CachedA recent live value kept in the local database inside the cache window.High (0.85)
ReferenceA public inventory or report value, not a real-time measurement.Medium (0.68–0.72)
ModeledReconstructed from measured rainfall/ET0 plus a documented balance.Medium (0.65–0.75)
ProxyA labeled stand-in when a direct measurement is unavailable.Low–medium (0.42)
FallbackA deterministic local generator used when the public API fails.Low (0.20–0.35)

Open data and services used

  • NASA POWER / MERRA-2: daily precipitation (PRECTOTCORR) and surface/root-zone soil wetness (GWETTOP, GWETROOT) for the prior ten years. power.larc.nasa.gov
  • Open-Meteo: 16-day precipitation, ET0 and maximum-temperature forecast for the country centroid and reservoir coordinates. open-meteo.com
  • Natural Earth 1:110m: country outline for the map and the offline fallback. Public domain. naturalearthdata.com
  • OpenStreetMap / Overpass: optional community reservoir inventory for countries without a curated list. openstreetmap.org
  • Public dam and aquifer tables: screening capacities and aquifer context for Algeria and Tunisia; details are shown per row and in the audit JSON.

Data honesty rules

  1. A value is marked live only when the API call succeeded and the fetch timestamp is stored.
  2. Reservoir storage is never called telemetry. It is modeled/blended and says so in the ledger and audit.
  3. No mapped aquifer means a root-zone proxy, not a hidden zero.
  4. No forecast means neutral 50 with low confidence, not an invented drought.
  5. No reservoir inventory means a visible national reference pool, not invented dam names.
  6. A what-if rainfall event is labeled as a simulation everywhere it appears.
